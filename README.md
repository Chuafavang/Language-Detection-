## 📌 Overview

This project develops a deep learning model capable of distinguishing **human-written** text from **AI-generated** text using contextual embeddings generated by **RoBERTa-base** and a **1D Convolutional Neural Network (CNN)**.

Unlike conventional text classification problems, the training data is provided at the **sentence level**, while the validation and test datasets are labelled at the **paragraph level**. To address this challenge, a sentence-level classifier was developed together with a probability aggregation strategy to generate paragraph-level predictions.

The project demonstrates the complete machine learning workflow including data exploration, model development, hyperparameter tuning, regularisation, evaluation, and deployment on an unseen Kaggle dataset.

# 🧠 Model Architecture

```text
Input (100 × 768)

        │
Conv1D (128 filters)

        │
Conv1D (256 filters)

        │
Conv1D (128 filters)

        │
Max Pooling

        │
Dropout

        │
Dense Layer

        │
Sigmoid Output
```

The final architecture was selected after extensive experimentation with different:

* Learning rates
* Batch sizes
* CNN filter sizes
* Number of epochs
* Dropout configurations
